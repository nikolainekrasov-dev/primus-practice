ДЕЛОВЫЕ ЗАМЕТКИ - мобильное веб-приложение (PWA), версия 1.2
=============================================================

Назначение: записи с совещаний, планёрок, собраний, конференций и деловых встреч.
Функции: создание, просмотр, редактирование, удаление и поиск заметок
(по словам, диапазону дат, диапазону времени и типу мероприятия).

Хранение данных (переключается в «Настройках»):
  1) База данных SQLite - файл notes.sqlite, таблица notes (движок SQLite
     скомпилирован в WebAssembly, библиотека sql.js, лицензия MIT - lib/LICENSE-sql.js.txt);
  2) Файлы на устройстве - каждая заметка отдельным файлом <id>.json в папке notes/.
  Файлы лежат в приватной файловой системе приложения (OPFS). Если браузер её
  не поддерживает, используется IndexedDB. Дополнительно есть выгрузка всех
  заметок в .json, одной заметки в .txt, скачивание notes.sqlite и загрузка
  заметок из файла .json/.txt.

Платформы: Android (Chrome, Яндекс Браузер), iOS/iPadOS (Safari 15.2+), ПК.
Приложение ставится на главный экран как обычное («Установить приложение» /
«На экран Домой») и после первого открытия работает без интернета.

СТРУКТУРА
  index.html              разметка четырёх экранов
  css/style.css           оформление под экран телефона
  js/app.js               логика интерфейса
  js/storage-sqlite.js    хранилище SQLite
  js/storage-files.js     хранилище в файлах
  lib/sql-wasm.js, .wasm  движок SQLite
  manifest.webmanifest, sw.js, icons/   установка и офлайн-режим

КАК ЗАПУСТИТЬ И ПРОВЕРИТЬ
Вариант А - опубликованная версия:
  https://nikolainekrasov-dev.github.io/primus-practice/notes-app/
  адрес открывают на телефоне.
Вариант Б - на компьютере:
  в этой папке выполнить  python -m http.server 8000
  и открыть http://localhost:8000 в Chrome; для вида телефона - F12, режим устройства.
  (При открытии index.html двойным щелчком браузер не даёт загрузить движок
  SQLite, тогда приложение само переключается на хранение в файлах.)

Порядок проверки (10-15 минут):
  1. Настройки (шестерёнка) -> «Добавить примеры заметок» -> назад.
  2. «+» -> заполнить заголовок, дату, время, тип, текст -> «Сохранить».
     Попробовать сохранить без заголовка - появится подсказка.
  3. Открыть заметку -> «Редактировать» -> изменить текст -> «Сохранить».
  4. Открыть заметку -> «Удалить» -> подтвердить.
  5. Ввести слово в строку поиска (например «меню»): совпадения подсвечиваются.
  6. Кнопка ☰ -> задать даты, время, тип: число активных фильтров видно на кнопке,
     «Сбросить поиск» возвращает полный список.
  7. Обновить страницу - заметки сохранились (SQLite).
  8. Настройки -> «Скопировать заметки в другое хранилище» -> выбрать «Файлы на
     устройстве» -> обновить страницу: заметки читаются из файлов .json.
  9. «Выгрузить все заметки в файл» и «Загрузить заметки из файла» - перенос
     данных между устройствами.

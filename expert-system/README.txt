ПИВНОЙ СОМЕЛЬЕ - прототип экспертной системы для ресторана «Ян Примус»
=====================================================================

Назначение: подсказать официанту или бармену, какое пиво из барной карты
предложить гостю с учётом заказанного блюда, вкуса, крепости и цвета.
Каталог - пример по пивной карте сети (страница «Пиво» на сайте yanprimus.ru,
Эбби Блонд - со страницы ресторана на Бауманской). Наличие на кранах конкретного
ресторана сверяется с его барной картой.

Запуск: открыть index.html в любом современном браузере (интернет не нужен).
  Вкладка «Консультация» - опрос из 5 вопросов, рекомендация (до 3 стилей с
  коэффициентом уверенности и позициями барной карты), кнопка «Как получен вывод?»
  показывает трассу сработавших правил, «Зачем этот вопрос?» - правила, в которых
  используется ответ.
  Вкладка «База знаний» - все правила в виде «ЕСЛИ ... ТО ...» и каталог подачи.

Опубликованная версия (открывается на телефоне или ПК):
  https://nikolainekrasov-dev.github.io/primus-practice/expert-system/

Состав:
  js/kb.js       база знаний: вопросы, 28 продукционных правил, каталог
  js/engine.js   машина вывода: прямой вывод, приоритеты правил,
                 коэффициенты уверенности и их объединение по формулам MYCIN
  js/ui.js       интерфейс пользователя
  tests/run_tests.js  12 тестовых сценариев (node tests/run_tests.js)

Как добавить правило: дописать объект в массив rules файла js/kb.js, например
  { id: 'R29', salience: 10, name: 'Портер к десерту',
    if: [{ attr: 'блюдо', eq: 'десерт' }, { attr: 'цвет', eq: 'тёмное' }],
    then: [{ attr: 'стиль', value: 'портер', cf: 0.7 }] }
и описание стиля в catalogue. Код машины вывода менять не нужно.
